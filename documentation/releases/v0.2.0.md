First maintained release of this fork for Home Assistant 2026.8+.

- Replace deprecated parent-device registration with via_device_id for heating zones, DHW, and energy producers.
- Add supported DHW operation, Comfort/Eco targets, and confirmed boost control.
- Add heating-curve slope/base and heating-activity temperatures within API-confirmed limits.
- Preserve existing entity identities, heat mode, and schedule presets.
- Distinguish unknown energy data from measured zero values.
- Serialize new zone writes, bound API requests, and sanitize diagnostics.
- Add technical documentation and automated regression tests against HA 2026.10.1.

Features are exposed only when the device confirms support. Installation and restart do not set temperatures, modes, boost, or curve parameters.

HACS installer: remeha_home.zip. Preserve the existing Remeha Home configuration entry and entities. Restart HA after installation to load new modules.

Based on msvisser/remeha_home and community contributions from hugo-leij/remeha_home, preserving their author history. See the repository README and technical documentation for limitations.
